# Entregables

Versiones finales de lo que se envía al INE. Los borradores se trabajan en `docs/`, `notebooks/` y `web/`.

| Carpeta | Contenido |
|---|---|
| `prototipo/` | Exportación del prototipo (PDF/PNG) y enlace al sitio |
| `guion-narrativo/` | Guion en PDF (3 a 5 cuartillas, storyline + difusión) |
| `video/` | Enlace al video (no subir el MP4) |
| `presentacion/` | Presentación ejecutiva (máx. 10 diapositivas) |

> Las cartas firmadas **no** se guardan aquí: el repositorio es público. Guárdenlas en una carpeta privada compartida.
